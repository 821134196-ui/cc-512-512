# 叉车动力电池换电管理系统

班组在叉车作业间隙预约换电、扫码交接旧电池、装新电池后复核固定与可用电量；
过热 / 槽位故障 / 充电中断 / 型号不兼容 / 错装 / 健康度过低的电池一律不得进入可用池。

- **零依赖**：Python 3 标准库（`http.server` + `sqlite3`），SQLite 保存全部绑定
- **模拟适配器**：后台线程产生充电桩信号（电量上升、温度漂移、过热隔离、随机中断）
- **本地照片**：检测照片存于 `data/photos/`，由健康检测页查看
- **角色**：调度员（预约/取消）、换电人（扫码/装入/复核）、维修人员（隔离/槽位故障）
- **界面**：工业白 + 深灰 + 电量绿；池位图显示编号、电量、预计充满时间；
  换电页左旧右新；高温有 🔥 图标、“高温”文字和温度值

## 启动（单条本地命令）

```bash
./run.sh                 # http://localhost:8000
SWAP_RESET=1 ./run.sh    # 重建演示数据
SWAP_PORT=8100 ./run.sh  # 换端口
```

启动后即含过热样例：

| 电池 | 情形 |
|---|---|
| BAT-A03 | 在 SLOT-1 充电中，温度 52.4℃ 且持续爬升，适配器检测到 ≥55℃ 后自动中断并隔离 |
| BAT-B04 | 已因 57.2℃ 过热 + 健康度 78 隔离 |
| SLOT-4 | 槽位故障（通信模块故障），其历史在充电池已带“槽位故障/充电中断”阻断 |

## 换电流程（换电队列页）

1. **预约**：选择叉车与作业间隙（如 `10:30-10:50`），叉车进入“待换电”。
2. **扫码交接（左列·旧电池）**：取下旧电池时点击“📷 扫码取下旧电池”，
   记录扫码时间、换电人、取下时电量，解除 车↔电池 绑定。
3. **装入新电池（右列·新电池）**：只列出型号兼容的电池；
   型号不兼容、低电量、过热、隔离、中断中的电池都会被事务拒绝（HTTP 409）。
4. **复核交车**：勾选“已复核机械固定”并确认可用电量 ≥ 60%，完成后叉车恢复作业。

## 互斥与并发

`active_bindings` 是互斥绑定的唯一事实来源：

```sql
PRIMARY KEY (battery_code)          -- 一块电池同一时刻只能连一辆车或一个槽位
UNIQUE (kind, target_code)          -- 每辆车 / 每个槽位至多一块电池
```

所有写操作在 `BEGIN IMMEDIATE` 事务内完成：两人并发扫码或抢装同一块电池时，
先拿到写锁的成功，另一方得到 409「已被占用」，不会出现重复绑定或一车两电。

## 健康隔离（仅维修人员）

- 健康检测结论写入 `health_checks` 后**只增不改**——SQLite 触发器拒绝任何
  UPDATE / DELETE；调度员角色调用隔离接口返回 403。
- 隔离动作会立即中断在充电池并解绑；槽位故障会中断该槽在充电池，
  并给电池打上「槽位故障 + 充电中断」阻断，离开可用池。
- 维修复检合格可解除隔离；一次完整正常的充电可清除中断类阻断
  （过热/低健康/错装结论不会被自动清除）。

## 测试

```bash
python3 test_system.py
```

13 个用例覆盖：

- **互斥绑定**：一电池不能同时上两槽、一槽不能装两电池、在车上的电池不能再充电
- **兼容型号**：错装被拒且不留脏绑定、兼容型号可完成全流程、固定/电量必须复核
- **故障隔离**：槽位故障中断充电并阻断、仅维修可隔离、结论触发器不可改
- **并发扫码**：经真实 HTTP 服务，两人同时扫码取下 200 + 409；
  两车抢装同一新电池 200 + 409，最终只有一个绑定
- **模拟适配器**：过热样例自动越限、中断、隔离
